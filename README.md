# Multilayer Perceptron

Projet de L2 Physique SPRINT, sur les bases du Multilayer Perceptron, un réseau de neurones utilisé en machine learning.

Les objectifs étaient de comprendre comment fonctionne ce réseau de neurones et de le programmer *from scratch* en *Python*, en utilisant des tableaux *NumPy*.

Une description approfondie du travail que j'ai réalisé se trouve dans le fichier *MLP.ipynb*.
